Approach

Simplest architecture that fits

I choose the simplest architecture the product can sustain: server-rendered HTML and progressive enhancement where they fit, Angular or React where the interface needs them.

Tools chosen per problem

I've shipped in JavaScript, TypeScript, PHP and C#, and use Go for small services where a single binary and a small dependency surface help.

AI-assisted, verified

I use AI agents for scoped, reviewable changes: clear task boundaries, persistent context, tests and code review. The agent drafts; the checks decide.
