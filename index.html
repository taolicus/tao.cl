Approach

Simple systems

I favour simple, maintainable architectures and the smallest amount of complexity a product needs.

That usually means server-rendered HTML, progressive enhancement and a small amount of JavaScript.

Pragmatic choices

I am technology-agnostic at work.

I have worked in JavaScript, TypeScript, PHP and C#, and reach for Go on personal project when a single binary and a small dependency surface make sense.

AI-assisted, human-reviewed

I use AI coding agents with an actively maintained Bootstrap workflow(opens in a new tab) for task scoping, persistent context and explicit verification, while keeping changes small and reviewable. Tests, version control and code review remain the checks that decide whether work is finished.
