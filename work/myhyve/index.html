Case study

Modernising the MyHyve Ticketing Portal

Mid-Level Engineer at Hyve Managed Hosting · Sep 2025 - Oct 2026

I worked on a production support portal at Hyve Managed Hosting. My work included upgrading Angular, simplifying how the application handled data and building features used by the support team.

Upgrading Angular

I initiated and implemented the upgrade from Angular 19 to 21 in stages. I used signals and rxResource to simplify state and data fetching, and moved API and business logic out of large components into services. I resolved dependency security findings and kept the application compatible with the existing deployment process.

Building a ticket notification preference

I consulted support engineers before implementing the preference across the Angular interface, C# API and SQL database. The feature went live and received positive feedback from the support team.

Improving production error reporting

I used Sentry to investigate recurring reports and updated the frontend to handle expected errors without reporting them as unexpected failures. That made the remaining reports easier to investigate.
