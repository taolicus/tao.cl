Case study

Modernising the MyHyve Ticketing Portal

Mid-Level Engineer at Hyve Managed Hosting · Sep 2025 - Oct 2026

At Hyve Managed Hosting, I worked on a production support portal used by the support team. My contributions included upgrading Angular, moving logic out of large components, delivering a notification preference across the application stack, and improving production error reporting.

Upgrading Angular and simplifying application code

I initiated and implemented the upgrade from Angular 19 to 21 in stages, keeping the application compatible with the existing deployment process.

Alongside the upgrade, I used signals and rxResource to simplify state and data fetching, moved API and business logic from large components into services, and resolved dependency security findings.

Delivering a notification preference across the stack

I consulted support engineers before implementing a ticket notification preference across the Angular interface, C# API and SQL database. The feature went live and received positive feedback from the support team.

Making production errors easier to investigate

Recurring Sentry reports included expected errors being reported as unexpected failures. I investigated the reports and updated the frontend to handle those cases without reporting them as unexpected failures. This made the remaining reports easier to investigate.
